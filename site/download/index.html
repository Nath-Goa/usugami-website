Android app

Download Usugami

Free, with no ads and no account, for Android 8.0 or newer. Usugami isn’t on the Play Store, so you install the APK file yourself. It takes about a minute.

On your phone, tap Get it on GitHub to download Usugami.apk (about 3 MB), then follow the install steps. Usugami comes in three editions, compared below; if you’re not sure, take this one.

Use Obtainium? Its badge adds Usugami with automatic updates. On Android 8.0 or 8.1, add it by hand instead.

No Android phone?

Usugami also works in your browser, on phones and computers. Your files stay on your device.

About internet access: Usugami itself has no internet permission and uploads nothing. The main Usugami.apk needs an internet connection only for text recognition (OCR): the first time you use each language, Google Play services downloads its recognition model (and again if Play services has removed it since). Everything else works offline. If you want text recognition built in, with no download ever, get Usugami-ocr.apk instead. If you don’t need text recognition at all, Usugami-lite.apk is the smallest.

All three editions are signed with the same key. Usugami and Usugami OCR are the same app (package name io.github.nath_goa.usugami), so you can switch between them at any time by installing one over the other; your files and settings are kept. Usugami Lite is an app of its own (io.github.nath_goa.usugami.lite, since version 1.5.1), so it installs next to them. Every release also has a SHA256SUMS.txt file for checking your download.

How Usugami OCR reads text

Usugami OCR has its own text recognition, open source and inside the app: the PaddleOCR PP-OCRv5 mobile models, run on your phone’s processor by Tencent’s ncnn. One model finds the lines of text on each page; then English, French and Spanish are read by PaddleOCR’s Latin-script model, and Hindi by its Devanagari model, which also reads English words. Nothing is downloaded and nothing leaves your phone, so it works in flight mode too. The engine and models are what make Usugami-ocr.apk about 11 MB bigger than Usugami.apk.

  • It reads printed text best: worksheets, letters, book pages, notices, including photos taken at an angle. Columns are read one after the other.
  • A page photographed upside down or sideways is read the right way up.
  • Handwriting, very small or blurred print, tables and maths are read less reliably. A sharp, well-lit photo taken straight on helps the most.
  • Each page takes a few seconds, longer on older phones. You can cancel at any time.
  • Its results differ from Google’s text recognition in the main edition: sometimes better, sometimes worse.

Obtainium

Obtainium is a free app that installs and updates apps straight from their GitHub releases. These links add Usugami to Obtainium with the right file and the signing certificate already set, so Obtainium refuses any APK that wasn’t signed with Usugami’s key:

  • Add Usugami to Obtainium (the main edition)
  • Add Usugami Lite to Obtainium
  • Add Usugami OCR to Obtainium

Open the link on your phone with Obtainium installed, and confirm. Usugami and Usugami OCR share a package name, so add only one of those two; Usugami Lite is an app of its own and can be added next to either. (Added Usugami Lite before version 1.5.1? Remove it and add it again with its link above, which has its new package name.)

On Android 8.0 and 8.1, Obtainium can’t read signing certificates, so it refuses to install an app that has a certificate set. On those versions, add Usugami by hand (below) and leave the certificate field empty.

Adding it by hand

In Obtainium, tap Add app, enter https://github.com/Nath-Goa/usugami as the app source URL, and set:

  • Filter links by regex: ^Usugami\.apk$ (or ^Usugami-lite\.apk$ for Usugami Lite, ^Usugami-ocr\.apk$ for Usugami OCR)
  • Expected signing certificate hashes: the SHA-256 fingerprint from Verify your download (leave empty on Android 8.0 and 8.1)

Setting names can differ slightly between Obtainium versions.

Install

Usugami isn’t on the Play Store, so you install the APK file yourself. It takes about a minute and works on Android 8.0 or newer. Menu names differ a little between phones.

  1. Download. On your phone, open this page and tap Usugami.apk (or Usugami-lite.apk or Usugami-ocr.apk). Your browser may warn that this type of file can harm your device. That’s a general warning for all APK files; tap Download anyway.
  2. Open the file. When the download finishes, tap Open. If you missed it, open the Files app (or My Files on Samsung), go to Downloads and tap the APK.
  3. Allow installing. The first time, Android says something like For your security, your phone currently isn’t allowed to install unknown apps from this source. Tap Settings, turn on Allow from this source, then go back. This permission is per app: it only lets the app you used (for example Chrome or Files) install apps.
  4. Install. Tap Install.
  5. Google Play Protect. Play Protect may say it hasn’t seen this app before, or that it doesn’t recognize the developer, and offer to Scan app. Scanning is safe: it sends details about the app to Google and then lets you install. If Play Protect ever says Usugami is harmful, don’t install it; please open an issue instead.
  6. Optional. Turn Allow from this source off again for that app.

Once it’s installed, Usugami is also in other apps’ Share menu: share images, PDFs, Word, PowerPoint, Excel or EPUB files to it from Files, Photos, a mail app or a chat, and they open in the right tool.

Where is “Install unknown apps”? (Samsung and other phones)

If you skipped step 3 or want to change it later:

  • Samsung: Settings → Apps → ⋮ (top right) → Special access → Install unknown apps → pick your browser or My Files → Allow from this source.
  • Pixel and most other phones: Settings → Apps → Special app access → Install unknown apps → pick the app → Allow from this source.
  • Or search for “unknown apps” in the Settings app.

Updating

Download the new APK and install it over the old one, the same way. Your files and settings are kept. To get updates automatically, use Obtainium.

Switching editions

Install Usugami.apk over Usugami OCR, or Usugami-ocr.apk over Usugami. No need to uninstall first. Usugami Lite is a separate app: install it next to the others, and uninstall the one you no longer want (save any PDFs you need to Downloads first).

Had Usugami Lite 1.5.0?

It was still the same app as Usugami. Since 1.5.1, Usugami Lite has a package name of its own, so Usugami-lite.apk installs as a new app, “Usugami Lite”, next to your old one, which is called “Usugami”. Save any PDFs you need from the old one, then uninstall it. If Obtainium updates it, remove it there and add Usugami Lite again: the old entry can’t update to the new app.

Had Usugami Offline?

Since version 1.5.0 it is Usugami OCR, with open-source text recognition built in instead of Google’s, and there is no Usugami-offline.apk any more. Install Usugami-ocr.apk over it: your files and settings are kept. If Obtainium updates it, change the app’s APK filter there to ^Usugami-ocr\.apk$, or remove it from Obtainium and add Usugami OCR again; until then Obtainium finds no update.

Had PDFer 1.0 or 1.1?

That was Usugami’s old name. Those were private test builds with a different package name, so Usugami installs as a separate app. Install Usugami, then uninstall the old “PDFer”.

“App not installed” or “the package conflicts with an existing package”
  • A Usugami from somewhere else is installed. Android only updates an app with an APK signed by the same key. If you got Usugami from another site, uninstall it first (save any PDFs you need to Downloads before you do), then install the APK from this page.
  • You’re installing an older version over a newer one. Android doesn’t allow that; download the latest release.
  • The download is incomplete or the phone is low on storage. Free some space, download the APK again and try once more.
  • The old PDFer 1.0 and 1.1 test builds don’t conflict: they have a different package name and install side by side.
Will Android’s new developer verification stop me installing Usugami?

Google has announced that Android will check that apps come from verified developers. As of October 2026 these checks don’t apply to apps downloaded from GitHub, so you can install Usugami as described above. Google has said it plans to extend the checks to all countries in 2027. If that changes how you install Usugami, this page will be updated.

On a computer: apksigner, checksums and build provenance

Signing certificate with apksigner from the Android SDK build-tools:

apksigner verify --print-certs Usugami.apk

The certificate SHA-256 digest line must read 6f4f23ade03e636a7cc368168944d0ccfc8132ef34c50bc5a46b0ca4cbbdf4ed. The certificate DN line says CN=Nathan Kumtakar, O=Usugami, but anyone can put any name in a certificate, so only the digest proves who signed the APK. (keytool -printcert -jarfile doesn’t work here: Usugami uses the newer APK signature schemes, which keytool can’t read.)

Checksums: download SHA256SUMS.txt from the same release, put it next to the APK you downloaded and run:

sha256sum -c --ignore-missing SHA256SUMS.txt          # Linux
shasum -a 256 -c --ignore-missing SHA256SUMS.txt      # macOS
Get-FileHash Usugami.apk -Algorithm SHA256            # Windows PowerShell: compare with the file

Your APK must show OK. (SHA256SUMS.txt lists all three editions; --ignore-missing skips the ones you didn’t download.) GitHub also shows each file’s SHA-256 next to it on the release page.

Build provenance: release APKs are built from Usugami’s source by the release workflow on GitHub Actions, which publishes a signed build-provenance attestation for each one. Check it with the GitHub CLI:

gh attestation verify Usugami.apk --repo Nath-Goa/usugami
